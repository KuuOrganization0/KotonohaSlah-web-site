# 言の葉Slash (Web Release)

## 概要
Unityで開発したブラウザゲーム『言の葉Slash』の公開用リポジトリです。

##  プレイURL
 [ここをクリックしてプレイ](https://kuuorganization0.github.io/KotonohaSlah-web-site/)

##  このリポジトリの役割
UnityのWebGLビルドファイルを管理し、GitHub Pagesを利用してホスティングを行っています。

- **使用技術** : HTML5, CSS3, JavaScript (WebGL)
- **デプロイ** : GitHub Pagesによる静的サイト公開

## 工夫点
- **ユーザビリティの向上**: タブレットやスマートフォンでも快適にプレイ出来るようにするため、画面サイズを自分で変えやすいようにプレイ画面をコンパクトに設計
- **デバイスごとに対応**: PCやタブレット,スマートフォンに応じてレイアウトを変化させるレスポンシブ対応を設計

## 今後の展望
- **コメント機能**: ゲームやブラウザに対してのコメントをすることが出来る機能の実装
- **SNSへのシェア機能**: SNS(Xなど)へ、自身の結果をシェアする機能の実装
- **デザインのブラッシュアップ**: おしゃれなデザインへ洗練やハンバーガーメニューの追加
